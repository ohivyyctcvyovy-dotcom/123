# Operação Zero — FPS Mobile (protótipo)

Jogo original de navegador, feito sem bibliotecas, modelos, texturas ou sons de terceiros. Os gráficos são desenhados em Canvas e os efeitos sonoros são sintetizados localmente com Web Audio.

## Jogar
Abra `index.html` num navegador moderno. No Android, publique a pasta num host estático HTTPS (por exemplo GitHub Pages) para jogar como site.

## Controles no celular
- Analógico virtual esquerdo: movimentar
- Arraste no lado direito: mirar
- ATIRAR: disparar
- R: recarregar
- PAUSAR: pausa/continuação

No computador: WASD/setas para mover, mouse para mirar, clique no botão ATIRAR e R para recarregar.

## Escopo atual
Protótipo local em primeira pessoa com cenário procedural, inimigos simples, disparos, recarga, vida, eliminações, áudio sintetizado e opções de desempenho/bots. Ainda não tem multiplayer, contas, lobby online, persistência, mapas/armas 3D realistas ou APK. O jogo é original e não utiliza assets proprietários de Point Blank.
