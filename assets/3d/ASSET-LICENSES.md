# Recursos 3D de terceiros

Modelos copiados para este projeto para uso em jogo. Licenças verificadas nas fontes públicas em 28/10/2026:

- `character-male-a.glb`: Kenney Mini Characters, CC0 1.0. Fonte: https://github.com/Hidencod/tge-assets (modelo derivado de Kenney). Uso, modificação e redistribuição permitidos sem atribuição.
- `fps-arms.glb`: WRAD ARMS, CC0 1.0. Fonte: https://github.com/wwwriks/wrad-arms. O autor informa 1.200 triângulos; braços rigados para viewmodel FPS.
- `assault-rifle.glb`: Flat Guns East, CC0 segundo o catálogo FPS Asset Kit. Fonte: https://github.com/petroulacl/fps-asset-kit; modelo atribuído ao OpenGameArt Flat Guns East.

Os modelos são estilizados/low-poly. Os arquivos foram incluídos localmente para evitar depender de links externos durante o jogo.
