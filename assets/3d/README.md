# Assets 3D para Operação Zero FPS

Arquivos GLB locais escolhidos para teste em dispositivos móveis:

- `character-male-a.glb` — personagem humano estilizado, aprox. 253 KB.
- `fps-arms.glb` — braços em primeira pessoa, aprox. 464 KB.
- `assault-rifle.glb` — rifle low-poly, aprox. 303 KB.

Licenças e fontes: `ASSET-LICENSES.md`.

Nota: os arquivos estão versionados no projeto, mas para aparecerem em jogo precisam ser carregados por Three.js/GLTFLoader e adaptados à câmera, escala, rig e sistema de jogo. A presença dos arquivos, por si só, não comprova integração visual ou teste em aparelho real.
